# Exam Rescue AI — genuine demo recording script

**Goal:** a crisp screen recording around 2–3 minutes showing real Telegram messages and the corresponding Switch setup. Never show a mockup as a live demo and never expose bot credentials.

| Approx. time | What to show | Suggested narration |
|---|---|---|
| 00:00–00:20 | Switch Console → Your Agents and the live Telegram group room. Show Study Coach and Quiz Master. | “I built Exam Rescue AI using two Codex agents, connected to a Telegram study group by Switch.” |
| 00:20–00:45 | Telegram: request for a simple K-means explanation. Show actual Study Coach response. | “The first agent teaches a topic in plain language and keeps context in the shared room.” |
| 00:45–01:20 | Quiz Master starts the five-question assessment. Show one real user answer and the immediate correction/score. | “A separate agent tests understanding, checks each answer and maintains a score.” |
| 01:20–01:40 | Show the already completed **5/5** result from the actual session. | “This completed quiz finished with five correct answers; no weakness was demonstrated.” |
| 01:40–02:15 | Show Quiz Master asking Study Coach to revise, then Study Coach's reply/lesson. | “Switch allows direct agent-to-agent handoffs in the same conversation. Study Coach reads the shared context and reinforces the material.” |
| 02:15–02:40 | Show Quiz Master reading the lesson and beginning the follow-up quiz. | “The examiner starts a fresh test from the revised concepts.” |
| 02:40–03:00 | Return to Switch Console room/README. | “The repository has declarative Switch templates and reproducible setup instructions.” |

**Before filming:** Ensure the Telegram bot token, private usernames, email addresses, chat IDs, and unnecessary personally identifying details are not visible. If displaying earlier chat history, make clear it is the previously recorded real session. Do not claim the follow-up quiz was fully graded unless you have actually completed it.

**Optional stronger demo:** Intentionally answer one *new* question incorrectly, show the feedback, and request Study Coach to explain that exact missed concept. Only demonstrate it if it works, and disclose that this is a new test run.

**Export:** MP4 or a platform-supported video format; upload to a link the judges can open. Paste the link in README and the submission form.
