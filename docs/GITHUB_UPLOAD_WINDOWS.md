# Publish Exam Rescue AI to GitHub — Windows, no terminal required

1. Download the `Exam_Rescue_AI_Submission.zip` file and right-click → **Extract All**.
2. Open the extracted `Exam_Rescue_AI_Submission` folder; you should see `README.md`, two `.template.yaml` files, `DEMO_SCRIPT.md`, `TEST_REPORT.md`, `SUBMISSION_CHECKLIST.md`, `docs`, and `scripts`.
3. Sign in to https://github.com/ and open https://github.com/new.
4. Repository name: **exam-rescue-ai-switch**. Set visibility to **Public**. Do not initialize with another README if possible; create the repository.
5. On the new repository page, choose **uploading an existing file** (or **Add file → Upload files**). Drag the **contents of the extracted project folder**, including the two subfolders, into GitHub's upload area. Check that the README and YAML files are included. Commit the upload.
6. Open `README.md` in GitHub and edit the two `TODO` lines with your real public repository and video URLs. Commit the update.
7. Upload your real demo recording to a shareable service. Test the video link in a private browser window.
8. Open the official hackathon submission page and supply the public repository and demo video links: https://www.wemakedevs.org/hackathons/switch . Submit before **11:59 PM IST, November 7, 2026**.

Important: Upload **files**, not only a ZIP file. Do not upload Telegram bot tokens, Codex credentials, `.env`, private user/chat information, or unredacted personal screenshots.

If GitHub web upload doesn't retain folders, use the 'Add file → Upload files' option for each folder separately, or use GitHub Desktop to publish the entire project folder.
